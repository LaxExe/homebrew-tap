# Homebrew Tap for LaxExe

Official Homebrew Tap for [Inline](https://github.com/LaxExe/Inline-MacOS-Win32Build).

## Installation

Install Inline with a single command:

```bash
brew install LaxExe/tap/inline
```

Or add the tap first and install:

```bash
brew tap LaxExe/tap
brew install --cask inline
```

## Updating

```bash
brew upgrade --cask inline
```

## Uninstalling

```bash
brew uninstall --cask inline
```
